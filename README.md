## Keybindings

Leader: `Space`

### Find

| Key          | Action       |
| ------------ | ------------ |
| `<leader>ff` | Find files   |
| `<leader>fg` | Live grep    |
| `<leader>fb` | Find buffers |

### Buffers

| Key          | Action          |
| ------------ | --------------- |
| `<Tab>`      | Next buffer     |
| `<S-Tab>`    | Previous buffer |
| `<leader>bd` | Delete buffer   |

### LSP

| Key          | Action             |
| ------------ | ------------------ |
| `gd`         | Go to definition   |
| `gr`         | Find references    |
| `K`          | Show documentation |
| `<leader>rn` | Rename symbol      |
| `<leader>ca` | Code action        |

### Formatting

| Key          | Action        |
| ------------ | ------------- |
| `<leader>fm` | Format buffer |

### fzf-lua

| Key     | Action    |
| ------- | --------- |
| `<C-j>` | Move down |
| `<C-k>` | Move up   |

### Window Navigation

| Key     | Action    |
| ------- | --------- |
| `<C-j>` | Move down |
| `<C-k>` | Move up   |
| `<C-h>` | Move left |
| `<C-l>` | Move right|

### Splitting and Resizing

| Key          | Action           |
| ------------ | ---------------- |
| `<leader>sv` | Split vertical   |
| `<leader>sh` | Split horizontal |
| `<C-down>`   | Move down        |
| `<C-up>`     | Move up          |
| `<C-left>`   | Move left        |
| `<C-right>`  | Move right       |
